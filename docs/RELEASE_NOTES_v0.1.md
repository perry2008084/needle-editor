# Project Needle v0.1

首次公开发布的 MVP 版本。

## 包含内容
- Windows x64 可执行文件
- PowerShell 安装脚本
- PowerShell 卸载脚本
- 许可证与项目说明

## 当前能力
- 新建文件
- 打开本地文本文件
- 保存 / 另存为
- 文本编辑
- undo / redo
- select all
- 左右移动、行首/行尾移动
- 插入前后空行
- 状态栏显示修改状态、光标行列、字符数

## 已知限制
- 仍处于早期 MVP 阶段
- GUI 编辑同步目前较粗，后续会优化
- 插件宿主与 Sublime 插件兼容层尚未接入
- 尚未提供代码签名的安装器
